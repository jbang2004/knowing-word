# 课程流程对齐说明

Knowing Word 不是把汉字做成孤立卡片，而是按课文、单字理解、顺序小测和专项巩固组成一个可连续完成的学习闭环。

| 学习层级 | 应用中的对应入口 | 关键规则 |
| --- | --- | --- |
| 学习首页 | 首页的四条学习路线与继续学习 | 显示每条路线的独立进度与上次学习位置。 |
| 课程地图 | “课本” | 按当前 2025 更新版呈现 26 课；精读、略读与课号不随机重排。 |
| 课文词语表 | 单课的词语地图 | 先走完该课三步内容理解路线，再看官方会认、会写、多音字与可选扩展字。 |
| 单字精讲 | 单字学习页 | 先看本课词语、图中嵌字、构形线索、原创学习语境和部件关系，再进入练习。 |
| 识字小测 | 单字页的“学会了，练习一下” | 题型包含词语语境、结构、图意/组字与按角色开放的书写；16 个多音字另有本课读音辨析。 |
| 拆一拆 | 专项 → 拆字 | 先选课、再选字，把部件按位置搭回完整汉字，然后书写。 |
| 红蓝字 | 专项 → 红蓝 | 将表意部首与其他部件分色，完成对应选择题。 |
| 空间结构 | 专项 → 结构 | 通过图形化结构卡选择左右、上下、包围等空间组织方式。 |
| 部件精讲 | “部件” | 按部件在课内出现次数排序，并可回到含该部件的真实词语。 |
| 学习记录 | “记录” → 单字记录 | 先按路线和课查看，再追溯每题的尝试次数、答对次数、最后结果与时间。 |
| 日日朗读 | 首页的朗读入口 | 范读、跟读和录音；录音保存到当前身份的私有对象存储并可跨设备回听。 |
| 个人空间 | 右上角“我的书包” | 学习昵称、年级、主题和进度同步到云端，并保留浏览器离线副本。 |
| 设计实验室 | `/playground/*` | 四个原站实验页均保留独立 URL，并升级为可交互的组件、动效、拼图与反馈演示。 |

## 过关规则

- 每道题都会保存尝试次数、答对次数和最后一次答案。
- 一个字只有在当前路线全部题目的最后一次答案均正确时，才标为已完成。
- 每条路线分别保存进度与续学位置；完成识字小测不会自动跳过拆字、红蓝或结构训练。
- 答错后会移除过时的“已完成”状态；继续学习停在当前未完成字和准确题号，不会跳字。
- 书写笔迹只在浏览器画布中存在；录音按身份隔离存储。公共项目不包含账号资料、登录信息或临时签名链接。

## 路由和数据

- 当前 365 个课内字记录与 65 个扩展字记录，连同 26 课共形成 2,007 条活动页面路由，全部可直接访问、刷新和分享，并由生产构建逐条回归验证。
- 官方层固定校验 26 课、200 个会认目标、16 个多音目标、220 个会写目标和 359 个去重课内字；六篇略读课不设置强制书写。
- 学习档案、答题/跳过/朗读事件和每日汇总保存到 D1；录音文件保存到 R2。
- 已登录工作区使用受信任身份头；其他访问者使用匿名设备身份。离线学习以本地更新时间与云端更新时间解决冲突。
- “清除学习记录”同时删除档案、事件、每日汇总、录音元数据和录音对象。
