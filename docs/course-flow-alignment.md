# 课程流程对齐说明

Knowing Word 不是把汉字做成孤立卡片，而是按课文、生字表、单字理解与完整过关组成一条可连续完成的主线；结构、拆字和红蓝作为选做复习，不再成为完成课程的前置条件。

| 学习层级 | 应用中的对应入口 | 关键规则 |
| --- | --- | --- |
| 学习首页 | “学习” | 按当前课的生字顺序继续主线，并在学完生字后开放朗读收尾。 |
| 课程地图 | “课本” | 按当前 2025 更新版呈现 26 课；精读、略读与课号不随机重排。 |
| 课文导读 | 单课的“课文导读” | 带着线索回到课本，点击重点词可进入对应字卡，完成后返回原段落。 |
| 生字表 | 单课的“生字表” | 按官方会认、会写、多音字与可选扩展字逐字学习；字卡和练习沿进入来源稳定返回。 |
| 单字精讲 | 单字学习页 | 先看本课词语、图中嵌字、构形线索、原创学习语境和部件关系，再进入练习。 |
| 单字完整过关 | 单字页的“学会了，练习一下” | 连续完成词语语境、结构、图意/组字、部件与按角色开放的书写；全部通过后，这个字即标为已学会。 |
| 拆字复习 | “复习巩固” → 拆字复习 | 选做；把部件按位置搭回完整汉字，然后书写。 |
| 红蓝复习 | “复习巩固” → 红蓝复习 | 选做；将表意部首与其他部件分色，巩固部件功能。 |
| 结构复习 | “复习巩固” → 结构复习 | 选做；通过图形化结构卡复习左右、上下、包围等空间组织方式。 |
| 部件精讲 | “部件” | 按部件在课内出现次数排序，并可回到含该部件的真实词语。 |
| 学习记录 | “记录” → 单字记录 | 先按路线和课查看，再追溯每题的尝试次数、答对次数、最后结果与时间。 |
| 日日朗读 | 首页的朗读入口 | 范读、跟读和录音；录音保存到当前身份的私有对象存储并可跨设备回听。 |
| 个人空间 | 右上角“我的书包” | 学习昵称、年级、主题和进度同步到云端，并保留浏览器离线副本。 |

## 过关规则

- 每道题都会保存尝试次数、答对次数和最后一次答案；当前一轮另行记录已经通过的题目。
- 一个字只有在同一轮完整过关中通过全部题目时，才标为已学会；跳过题目不会误触发完成页。
- “已学会”是一次真实达成的学习成就，之后复习答错只更新练习记录，不会反向抹掉成就。
- 结构、拆字、红蓝分别保存复习进度与续学位置，但不再强制串成第二条必修路线。
- 字卡、练习、下一个字与完成页共享同一个 `returnTo` 上下文，因此从生字表、课文导读、学习首页或记录页进入时，会稳定返回原入口。
- 当前课全部生字完成后即可朗读收尾；是否完成三项选做复习会单独展示，不影响课程完成。
- 书写笔迹只在浏览器画布中存在；录音按身份隔离存储。公共项目不包含账号资料、登录信息或临时签名链接。

## 路由和数据

- 当前 365 个课内字记录与 65 个扩展字记录按 26 课生成有界学习路由；正式学习页面均可直接访问、刷新和分享，并由生产构建逐条回归验证。
- 官方层固定校验 26 课、200 个会认目标、16 个多音目标、220 个会写目标和 359 个去重课内字；六篇略读课不设置强制书写。
- 学习档案（含每日统计）与答题/跳过/朗读事件保存到 D1；录音文件保存到 R2。
- 已登录工作区使用受信任身份头；其他访问者使用匿名设备身份。根布局只创建一个学习档案实例，每次变更立即进入串行保存队列，路由切换不会再取消尚未落库的进度；服务端档案是权威数据，本地副本负责离线恢复和乐观更新。
- “清除学习记录”同时删除档案、事件、录音元数据和录音对象。
